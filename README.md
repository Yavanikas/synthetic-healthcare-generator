# Synthetic Healthcare Data Generator

A privacy-preserving system that generates realistic synthetic healthcare datasets using machine learning — enabling safe data sharing without exposing patient information.



## Key Features

*  Privacy-preserving synthetic data generation
*  Real vs Synthetic data evaluation
*  Automated insights on data similarity
*  Interactive UI built with Streamlit
*  End-to-end pipeline: Upload → Process → Analyze



##  Tech Stack

* Python
* Streamlit
* Pandas
* Scikit-learn
* Matplotlib



##  How It Works

1. Upload real healthcare dataset
2. Data is preprocessed and cleaned
3. Synthetic data is generated using ML models
4. Privacy noise is injected
5. Results are evaluated and visualized




##  Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```



##  Use Cases

* Healthcare research
* AI model training without sensitive data
* Data sharing between institutions
* Privacy-compliant analytics
